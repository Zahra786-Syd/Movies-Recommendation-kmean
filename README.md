# 🎬🧩 Movie Recommendation System using K-Means Clustering 📊✨

## 🎯 THE IDEA
🍿 A machine learning model that groups movies (or users) into meaningful clusters 🎞️, using the **K-Means Clustering** algorithm 🌀 — an **Unsupervised Learning** technique, meaning the model discovers hidden patterns in viewing/rating behavior all on its own, with no predefined labels to learn from! Movies with similar genre patterns, ratings, or user preferences 🎭 are grouped together, and recommendations are generated by suggesting other movies from the same cluster. 🤖

💡 Imagine a streaming platform 📺 wanting to recommend "similar" movies to what a user just watched — this project replicates exactly that behind-the-scenes clustering logic that powers "You Might Also Like" sections. 🎯

## 📂 DATASET DETAILS
📥 **Source:** Kaggle — [The Movies Dataset (MovieLens)](https://www.kaggle.com/rounakbanik/the-movies-dataset) 🔗

📋 **Key Features:**
▸ 🎬 Movie Title / ID
▸ 🎭 Genre(s)
▸ ⭐ Average Rating
▸ 👥 User Ratings (used to build a user–movie rating matrix)
🎯 **No target/label column** — this is an unsupervised clustering task!

## ⚙️ THE WORKFLOW
1️⃣ 📥 Loaded and explored the MovieLens dataset from Kaggle
2️⃣ 🧹 Cleaned the data and merged movies with their ratings
3️⃣ 🔢 Built a user–movie rating matrix / genre-based feature matrix
4️⃣ 📏 Scaled the features for fair distance-based clustering
5️⃣ 📊 Used the **Elbow Method** to determine the optimal number of clusters (K)
6️⃣ 🤖 Trained the K-Means model to group similar movies together
7️⃣ 🎨 Visualized the clusters using scatter plots
8️⃣ 🎬 Generated recommendations by suggesting movies from the same cluster as a user's favorite
